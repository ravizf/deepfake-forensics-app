Privacy

Upload handling and data retention.

SnapTrace is a research prototype, so privacy expectations are stated plainly.

Uploaded Images

  • Uploaded files are used only to run the analysis, heatmap, history, and report workflow.
  • Files are stored on the application instance for case history and report access.
  • Files are not shared with third parties by the application.
  • Public demo samples use bundled sample files, not reviewer personal uploads.

Retention

  • This prototype retains uploaded evidence until deployment storage or the database is cleared.
  • Reports include case ID, timestamp, file hash, prediction, confidence, and limitations.
  • Do not upload sensitive personal evidence unless you are comfortable with prototype storage.
  • This system is for research and education only, not legal proof.
